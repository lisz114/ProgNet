O que é HTML

HTML é uma linguagem de estilização usada para criar páginas web. A estrutura do HTML é formada por:


"!DOCTYPE html" = Usado para declarar que o documento é do tipo HTML;

"html lang = " = Indica a linguagem da página;

"head" = É a "cabeça" da página, ou seja, é aqui que colocamos o nome, o titulo, a estilização e etc...

"meta charset" Indica a versão do HTML;

"title" = Indica o nome/titulo da página web;

"body" = É o "corpo" da página. É aqui onde o conteúdo da página se encontra.
